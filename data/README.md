# Data Directory

This directory contains the sample input files used by the AutoCAB prototype.

## Files

- `sample_workflow_traces.json`: synthetic workflow traces for the default demo
- `sample_screen_capture.json`: pre-exported screen activity timeline for the screen-capture adapter
- `sample_terminal_session.log`: sample terminal session log for ingestion
- `sample_skill_catalog.json`: sample skill catalog used for matching

Project proposal and team reference documents are stored under `docs/`.
